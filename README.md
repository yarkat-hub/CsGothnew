# CsGoth: мини-приложение Telegram

## Без домена и сервера: Windows
Распакуй архив (Извлечь всё), открой папку и дважды щёлкни `start.bat`. Он сам поставит Node.js (если нужно), игру и бесплатный тоннель Cloudflare, спросит токен бота и твой Telegram ID, и покажет адрес для BotFather. Адрес меняется при каждом запуске. Для проверки подходит, для настоящих платежей нужен постоянный сервер.

## Самый простой способ: установщик
На сервере с Ubuntu 24.04 (от root) в папке проекта выполни `bash install.sh`. Он спросит домен, токен бота и твой Telegram ID, сам поставит всё нужное, включит https и автозапуск и будет делать ежедневную копию базы. Подробности ниже нужны только если хочешь настроить вручную.

Игра работает как Telegram Mini App: игрок открывает её из бота, вход идёт автоматически по аккаунту Telegram (без паролей и почты).

## Настройка Telegram
1. В @BotFather создай бота (`/newbot`) и сохрани токен.
2. Создай мини-приложение: `/newapp`, выбери бота, укажи адрес твоего сайта с https (`PUBLIC_URL`) и короткое имя, например `play`.
3. Ссылка на приложение будет вида `https://t.me/ИмяБота/play`, её и раздавай игрокам. Для кнопки «Играть» в боте: `/setmenubutton` и тот же адрес сайта.
4. Свой числовой Telegram ID узнай у бота @userinfobot. Он нужен для админки.

## Запуск
1. Установи Node.js 18+ и выполни `npm install`.
2. Запусти (Mac и Linux):
   `BOT_TOKEN=токен ADMIN_TG_IDS=твой_id MINIAPP_LINK=https://t.me/ИмяБота/play PUBLIC_URL=https://твой-сайт node server.js`
   Windows PowerShell: `$env:BOT_TOKEN="токен"; $env:ADMIN_TG_IDS="твой_id"; $env:MINIAPP_LINK="https://t.me/ИмяБота/play"; $env:PUBLIC_URL="https://твой-сайт"; node server.js`
3. Открывай игру через бота в Telegram. Обычная вкладка браузера покажет подсказку открыть игру в Telegram.

Для Telegram нужен адрес с https и настоящим сертификатом, поэтому для проверки удобно использовать тоннель (например Cloudflare Tunnel или ngrok) на `localhost:3000`.

## Переменные
- `BOT_TOKEN`: токен бота (по нему проверяется подпись входа)
- `ADMIN_TG_IDS`: Telegram ID админов через запятую; админ-панель появляется внизу вкладки «Кейсы»
- `MINIAPP_LINK`: ссылка на приложение, из неё строятся реферальные ссылки
- `PUBLIC_URL`: адрес сайта с https
- `CASHBACK_PCT` (по умолчанию 5), `PORT`, `DB_FILE`
- `DEMO_PAYMENTS=1`: тестовое пополнение без денег, в боевой версии не включай

## Платежи: Telegram Stars (без домена и адреса)
Включаются сами, как только задан `BOT_TOKEN`. Игрок платит звёздами прямо в Telegram, сервер сам забирает оплату у Telegram (тоннель или домен для этого не нужны, но сервер должен быть запущен). `STAR_GOLD` (по умолчанию 1) задаёт, сколько голды игрок получает за 1 Star, подбери курс под себя с учётом комиссии Telegram и условий вывода звёзд (проверь их в правилах Telegram). Промокоды и рефералы работают и со Stars.

## Платежи (Platega)
Задай `PLATEGA_MERCHANT_ID`, `PLATEGA_SECRET`, `PLATEGA_METHOD` (2 = СБП, 11 = карты). Адрес колбэка в кабинете указывать не обязательно: сервер сам раз в 15 секунд спрашивает у Platega статус неоплаченных платежей, а когда игрок возвращается в игру, проверяет его платежи сразу. Если постоянный адрес есть, колбэк `PUBLIC_URL/api/pay/webhook` можно тоже указать, повторного начисления не будет. Платёж открывается во внешнем браузере, после оплаты игрок возвращается в Telegram, и баланс обновляется. Нужно, чтобы сервер был запущен. Колбэки CHARGEBACKED и PARTIALLY_REFUNDED пишутся в таблицу admin_log.

## Промокоды и партнёры
В админ-панели раздел «Промокоды и партнёры»: код, бонус игроку в %, Telegram ID партнёра и его доля, лимит. Партнёр должен хотя бы раз открыть мини-апп. Бонус и доля начисляются голдой после подтверждённой оплаты, один раз на игрока и код.

## Рефералы и кэшбэк
Реферальная ссылка берётся со вкладки «Рефералы». Кэшбэк возвращает `CASHBACK_PCT`% потраченной на платные кейсы голды раз в 7 дней.

## Шансы
Шансы и вес скинов задаются в `CASES` в `server.js` (вес из 10000) и показываются игрокам по ссылке «шансы» у каждого кейса. Скрытые или отличающиеся от показанных шансы запрещены правилами большинства лицензий и платёжных систем.

## Резервные копии
Все аккаунты и балансы лежат в файле `csgoth.db`, делай его копию каждый день.

## Кнопка «Играть» в боте
При запуске сервер сам ставит боту кнопку меню «Играть» с текущим адресом, а на команду /start присылает кнопку «Играть». Поэтому при смене адреса тоннеля BotFather обновлять не нужно, достаточно открыть бота. Ссылки-приглашения вида `t.me/бот/play` (рефералы) работают только после `/newapp` в BotFather, и адрес там придётся менять вместе с адресом тоннеля.

## Вывод скинов на Steam
Вкладка «Вывод»: игрок выбирает регион, пишет Steam-логин и отмечает скины. Скины списываются, создаётся заявка. Админ видит её в админ-панели (вкладка «Профиль») и после ручной выплаты нажимает «Выплачено», а при отказе «Отклонить», тогда скины вернутся игроку. Деньги на Steam автоматически не отправляются, выплату делаешь ты сам или через своего поставщика.
Настройки: `WITHDRAW_RATE` (рублей за 1 G, по умолчанию 1), `WITHDRAW_FEE_PCT` (комиссия, по умолчанию 5), `WITHDRAW_MIN` (минимум в рублях, по умолчанию 100), `WITHDRAW_NEED_DEPOSIT` (сколько надо пополнить до первого вывода, по умолчанию 100; защищает от вывода бесплатных скинов).
